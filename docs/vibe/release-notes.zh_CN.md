# Vibe 伴侣 v0.8.4

## 本次更新

蓝牙和 Wi-Fi 均可连接电脑，语音、回车、Agent 提醒及收音机均可通过蓝牙使用。
公司网络不便让设备接入时，直接通过蓝牙连接 Mac。收音机由电脑联网获取并解码。

本版取消配对码：电脑发现设备后点击连接，在设备上确认；可同时保持 Wi-Fi 和蓝牙，
链路失效时自动切换。全新设备可直接从蓝牙开始，Wi-Fi 配置页增加十秒未弹出时的
手动打开地址提示。同步改进重新配对、电台缓冲与语音后恢复，以及黑屏确认按键。

面向 FoloToy AI Passport 的社区固件及 macOS 客户端，具体版本以 Release 标签和安装包
文件名为准。

## 包含功能

- 使用设备麦克风进行无线“按住说话”输入，单独按键负责回车；番茄钟或收音机运行时
  仍可使用语音。
- 接入 Codex、Claude Code、OpenCode、DeepSeek Harness、ZCode、Gemini CLI 和 Qwen Code，
  事件覆盖按具体集成区分。首条提醒立即发送，同一 Agent／会话随后一秒内的其他回调
  被忽略，不转发对话内容。
- 紧凑提醒浮窗，亮屏响铃、五秒自动消失，按键关闭时仍执行原功能。
- 手动开始下一阶段的专注／休息轮转、四页天气、亮暗主题与定时切换，以及最多 20 台
  电台的桌面搜索、选台和排序。
- 通过 BLE 发现附近设备，或发现同一 Wi-Fi 的设备；两条链路合并为一条设备记录。
  电脑发起连接，设备确认。可同时保持两条连接，业务选择一条可用链路。
  更换电脑需要设备确认，并撤销原电脑授权。
- 电台在电脑解码，通过 UDP 或 BLE 发送至设备的有界缓存。当前 16 kHz 单声道格式
  可缓存 1.6 秒编码音频，启动预缓冲 1.2 秒，高频细节有所减少。新 App 同时兼容此前的
  24 kHz 格式；升级时使用配套的新固件与客户端。
- 手机配置最多五个已记住 Wi-Fi，自动重连，支持设备与桌面配置同步；首次启动即可
  选择蓝牙。
- 黑屏时首次按键只亮屏，不执行菜单或审批操作；首页语音与回车仍可直接使用。
- 菜单栏 macOS App，一个 DMG／ZIP 同时包含 Apple Silicon 和 Intel；配套 ESP32-C3、
  8 MB Flash 的已验证合并固件。

## 安装

使用同一 Release 的固件和 App。附件 `INSTALL.txt`／`INSTALL.zh_CN.txt` 说明 Mac 安装、
BlackHole 2ch、输入法、授权和配对。源码中的 `docs/vibe/README.zh_CN.md` 说明设备刷写和
操作。合并固件 `FoloToy-AI-Passport-full.bin` 从 `0x0` 写入，全新安装可能重置设备设置。
下载后对照 `SHA256SUMS.txt`。

安装包使用免费 ad-hoc 临时签名，未经 Apple 公证。首次打开或更新可能需要单独确认及
刷新快捷键权限。不需要付费 Apple 账号，App 不使用钥匙串。

## 验证边界

构建、主机测试和设备验收分别报告。本地 Intel 候选已通过自动检查及用户参与的语音／
回车、电台／恢复、BLE 重新配对、手机 Wi-Fi 和已安装 Hook 验收。耗电与电池待机由
用户留待后续独立测试。干净系统安装、Apple Silicon／macOS 13 实际运行、真正的多电脑／
多设备仍待验证；发布工作流单独记录构建与主机测试结果。当前客户端仅支持 macOS；桌面端控制一台选中设备，设备同一时刻授权
一台电脑，换机时替换授权。Agent 覆盖取决于版本和本地入口；收音机取决于
电台源、网络、格式及可用设备资源。配套包附第三方声明，正式发布前还需核对该版本的
最终验证结果。
